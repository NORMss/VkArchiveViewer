# VK Archive — структура файлов (messages)

> Памятка по формату выгрузки персональных данных VK (раздел **Сообщения**).
> Используется парсером `VkArchiveParser`. Не нужно перечитывать сам архив —
> вся нужная информация о формате собрана здесь.

## Кодировка

Все `.html` файлы в кодировке **windows-1251** (`<meta charset="windows-1251">`).
Декодируется в приложении вручную через `Cp1251.decode(bytes)` (чистый Kotlin,
работает на всех платформах). Текст содержит HTML-сущности (`&#128512;`, `&#33;`,
`&laquo;` и т.п.) и теги `<br>` — их разворачивает `HtmlText`.

## Идентификатор владельца архива

В `<meta name="jd" content="...">` лежит base64 JSON вида
`{"user_id":209348885,"time_current":1736623771}`.
`user_id` — это владелец архива. В диалоге его сообщения = «исходящие»
(автор сообщения ссылается на `vk.com/id<owner>`).

## Дерево каталогов

```
Archive/
  index.html                       — главное меню выгрузки
  style.css
  messages/
    index-messages.html            — СПИСОК всех чатов (peer -> имя)
    <peerId>/                       — папка одного чата, имя = peer id
      messages0.html               — страница 1 (САМЫЕ НОВЫЕ сообщения)
      messages50.html              — страница 2
      messages100.html             — страница 3
      ...
      messages900.html             — последняя страница (самые старые)
```

- Каждый каталог чата называется по **peer id**:
  - `-157369801` (отрицательный) — сообщество / паблик (`vk.com/club157369801`).
  - `2000000001`+ — беседа (чат с несколькими участниками).
  - положительное число — личный диалог с пользователем (`vk.com/id<n>`).
- В каждой папке файлы `messagesN.html`, где `N` кратно 50 (по 50 сообщений на
  страницу). `messages0.html` — самые свежие сообщения, дальше по возрастанию N
  идут более старые.

## `messages/index-messages.html` — список чатов

Каждый чат — блок:

```html
<div class="message-peer">
  <div class="message-peer--id">
    <a href="-220050914/messages0.html">Cainiao</a>
  </div>
</div>
```

- `href` → относительный путь к первой странице чата; первый сегмент = peer id.
- текст ссылки `<a>` → отображаемое имя чата.

## `messagesN.html` — страница сообщений

Хлебные крошки в заголовке (`_header_inner`) содержат имя чата в последнем
`<div class="ui_crumb">`.

Каждое сообщение:

```html
<div class="message" data-id="1741486">
  <div class="message__header">
    <a href="https://vk.com/club157369801">СберКот</a>, 25 дек 2024 в 8:15:45
  </div>
  <div>
    Текст сообщения с &#128512; и переносами<br><br>
    <div class="kludges">
      <div class="attachment">
        <div class="attachment__description">Фотография</div>
        <a class='attachment__link' href='https://sun9-63.userapi.com/....jpg?...'>https://...</a>
      </div>
    </div>
  </div>
</div>
```

Поля одного сообщения:

| Что               | Где                                                              |
|-------------------|------------------------------------------------------------------|
| id                | `div.message[data-id]`                                           |
| автор (имя)       | текст `div.message__header > a`                                  |
| автор (id/ссылка) | `href` той же `<a>` (`vk.com/id<n>` или `vk.com/club<n>`)        |
| дата              | текст в `message__header` после `</a>`, формат `25 дек 2024 в 8:15:45` |
| текст             | прямой текст внешнего `<div>` (до `div.kludges`)                 |
| вложения          | `div.kludges > div.attachment` (может быть несколько)            |

Вложение (`div.attachment`):
- `div.attachment__description` — тип: «Фотография», «Файл», «Видеозапись»,
  «Аудиозапись», «Стикер», «Ссылка», «Документ» и т.п.
- `a.attachment__link[href]` — URL вложения. Для фото это прямой URL картинки
  (`*.userapi.com/...jpg`). **Важно:** URL'ы вложений — это удалённые ссылки VK с
  подписью и сроком годности; для старого архива часть из них уже недоступна.

### Пагинация внутри чата

Внизу страницы блок `div.pagination` со ссылками `messages0.html`,
`messages50.html`, … Парсер не обязан его читать: страницы перебираются по
шаблону `messages{N*50}.html`, пока файл существует.

## Дата сообщения

Формат: `D mmm YYYY в H:MM:SS`, месяц — русское сокращение:
`янв фев мар апр май июн июл авг сен окт ноя дек`.
Парсится в `MessageDate` (год/месяц/день/час/мин/сек) для сортировки.

## Замечания для приложения

- Список чатов сам по себе НЕ отсортирован по дате — порядок надо считать,
  взяв дату первого (самого нового) сообщения из `messages0.html` каждого чата.
- Количество сообщений в чате ≈ `(номер последней страницы / 50 + 1) * 50`
  минус добор на последней; точное число — суммой по всем страницам.
- Медиа-вложения для общей галереи собираются обходом всех чатов и страниц.
